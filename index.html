Catalogatore Telegram

I tuoi messaggi, in ordine.

Importa gli export e cataloga con un clic o con la tastiera. Nessun collegamento a Telegram o MT5.

Apri o ripristina

Seleziona uno o più file HTML dell’export Telegram. I file sono letti in ordine naturale per nome (per esempio messages.html, messages2.html, messages10.html). Il database viene salvato nel browser di questo dispositivo.

Per aggiungere i collegamenti a un catalogo già salvato, usa Aggiorna collegamenti da HTML e seleziona gli HTML originali. I casi precedenti riconoscibili possono essere convertiti; gli altri restano da verificare.

Nessun database caricato.

Categorie

Ordini: neword = nuovo pendente; updord = modifica pendente; clsord = annullamento pendente; openord = notifica apertura del pendente.
Posizioni: newpos = apertura diretta a mercato; updpos = modifica posizione aperta; clspos = chiusura singola o multipla.
Altre: trash, recap e warning. Uno stop loss già raggiunto è warning. Il catalogatore non esegue controlli sul conto o chiusure.

I vecchi cataloghi vengono convertiti solo dove riconoscibili; i casi ambigui restano da verificare. La classificazione originale resta nel backup.

Scorciatoie

Clicca su una casella e premi il tasto desiderato. Frecce ← → per navigare; Esc per tornare qui.

Backup e allegati

Esporta regolarmente il database. Per visualizzare le immagini disponibili, seleziona la cartella completa dell'export; la selezione degli allegati dura fino alla chiusura della pagina.

Sono esclusi i messaggi precedenti e quelli senza data riconoscibile. Il database nel browser non viene modificato; conserva anche un backup completo.

Il backup contiene i messaggi e le classificazioni. Se lo carichi nella repository pubblica, saranno visibili a tutti. Ripristinare un backup sostituisce il database locale.

Inserisci gli ID Telegram dei messaggi neword o newpos, separati da virgole. Svuota il campo per usare i collegamenti automatici.
