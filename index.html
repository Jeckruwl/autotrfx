Catalogatore Telegram

Un messaggio alla volta, senza collegamenti a Telegram o MT5.

Privato nel tuo browser

I tuoi dati

Importa entrambi i file messages.html e messages2.html, oppure ripristina un backup JSON già esportato. I file vengono elaborati sul tuo dispositivo.

I dati rimangono in questo browser finché non li elimini o cancelli i dati del sito. Esporta regolarmente un backup. Se carichi il JSON nella repository pubblica, messaggi e catalogazioni saranno visibili a tutti.

Nessun database caricato.

Come vuoi catalogarlo?

Puoi scegliere più categorie per messaggi con più istruzioni. trash non è combinabile con le altre.

I messaggi senza testo possono contenere allegati: non sono automaticamente trash. Gli eventi di servizio con ID sono inclusi. La data è riportata come nell'export, senza conversione di fuso orario. Per una copia consultabile anche fuori da questo browser usa il backup JSON.
